Hilfe

Der NetzScanner zeigt alle Geräte im Netz mit IP, Name, MAC-Adresse und offenen Ports.

Übersicht

Oben die Kennzahlen, darunter die Geräteliste. Klick auf eine Zeile zeigt Details rechts.

Web-Zugänge

Hat ein Gerät einen Web-Port offen (z. B. 80, 443, 5000, 8080), erscheint ein blauer Link. Ein Klick öffnet die Oberfläche des Geräts in einem neuen Tab.

Topologie

Zeigt, welches Gerät an welchem hängt (Router → Switch → Geräte). Quelle: Uplink-Angaben (später LLDP/SNMP).

Hinweis

Ziel eingeben (z. B. 192.168.1.0/24 oder eine einzelne IP), optional Ports (22,80,8000-8100) und „Scan starten“. Geräte werden per TCP-Verbindung gefunden, MAC-Adressen nur im eigenen Subnetz (aus der ARP-Tabelle). Geräte, die weder offene Ports noch ARP-Antwort liefern, bleiben unsichtbar. Standardmäßig sind nur private Netze erlaubt. Nur in Netzen scannen, für die du die Erlaubnis hast. Server startet nur lokal; für andere Rechner --listen 0.0.0.0:8484.
